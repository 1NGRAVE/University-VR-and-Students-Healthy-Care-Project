## 论文技术要点

### 系统核心架构

```
传感器层 → LSL数据流 → 信号处理(Python: NeuroKit2/MNE/HeartPy)
→ AI分析引擎(6层可解释管道) → JSON/HTTP :5000 → VR渲染(Unity+Quest 3)
```

### 硬件方案

| 方案 | 传感器 | 成本 | 特征维度 |
|------|--------|------|----------|
| 方案一（低成本） | Polar H10 + VR内置追踪 | ~¥600 | ~12维 |
| 方案二（高精度） | +Muse S EEG + Empatica E4 | ~¥15,000 | ~31维 |

### 六层AI管道

```
L1 生理状态评估 → L2 心理情绪评估 → L3 认知状态评估
→ L4 综合状态融合 → L5 推荐决策引擎(RF+SVR+规则) → L6 VR适配输出
```

### 四大创新点

1. **"一源多用"策略**：单一HRV信号→身/心/脑三维指标提取
2. **六层可解释AI管道**：安全规则→生理边界→ML分类→回归→上下文微调→VR适配（全链可追溯，非黑盒）
3. **闭环VR生物反馈**：显性HUD（HR环/EEG柱/GSR水滴/呼吸球）+ 隐性环境自适应（色温/音频/粒子/光照）
4. **渐进式硬件架构**：$80起入门，共享管道，无缝升级

### 四类VR运动场景

| 场景 | 训练类型 | 目标情绪 | 音频 | 环境自适应 |
|------|----------|----------|------|-----------|
| 海滩日落 | 呼吸训练 | 紧张/焦虑(HA-HV) | 432Hz+海浪 | 暖橙↔深蓝 |
| 山湖 | 太极引导 | 平静/满足(LA-LV) | 528Hz+自然 | 暖黄稳定光 |

| 抽象空间 | 高强度挑战 | 兴奋/激动(HA-LV) | 140-160BPM | 霓虹随HR加速 |

### ⚠️ 重要修正（论文已更新）

1. **TBR（Theta/Beta比值）**：原论文初稿引用了"Monastra发现TBR诊断敏感性>85%"，这是**错误表述**❌。Arns等(2013) meta分析明确结论是TBR"不能被视为可靠的诊断指标"(d=0.62~0.75, 异质性显著)。2024年Boxum等更新meta分析发现控制慢速Alpha峰值频率后TBR效应量降至**非显著水平**(d=-0.212~+0.218)。论文已修正为：TBR作为"趋势监测指标"而非"诊断标准"使用。

2. **Davidson FAA模型**：Harmon-Jones & Allen (1998) 重大修正——愤怒（负效价+趋近动机）表现为**左侧**前额叶激活，打破了简单"左正右负"效价映射。#EEGManyLabs大规模重复发现效应量远小于原始报告。论文已修正为：FAA作为"实时状态指示器"而非"稳定特质标志物"。

3. **Polar H10动态运动**：高强度VR运动场景下信号丢失率可达40.4%，论文已增加此局限性并建议配套信号质量监测策略。
